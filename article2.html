Основные достижения

16.09.2026

Главным триумфом Джеймса Гослинга стала концепция виртуальной машины и создание языка программирования Java. Чтобы вывести классическую фразу на экран, программисты используют код System.out.println("Hello, World!"); . Для запуска программы в консоли достаточно нажать клавишу Enter. Помимо Java, Гослинг создал самый первый текстовый редактор Emacs для системы UNIX и распределенную оконную систему NeWS.

Список терминов

Java
Строго типизированный объектно-ориентированный язык программирования, разработанный компанией Sun Microsystems.
JVM (Java Virtual Machine)
Виртуальная машина Java — основная часть среды времени выполнения, которая читает и выполняет скомпилированный код.
Байт-код
Машинно-независимый код низкого уровня, который генерируется транслятором и исполняется виртуальной машиной.
Кроссплатформенность
Способность программного обеспечения работать с несколькими аппаратными платформами и операционными системами без переписывания кода.

История версий Java

Основные и самые важные обновления языка Java
Версия Год выхода Статус Ключевые изменения
Java 1.0 1996 Базовый Первый официальный публичный релиз языка.
Java 5.0 2004 Крупное обновление Появление дженериков (generics), аннотаций и удобного цикла for-each.
Java 8 2014 Крупное обновление Революция в коде: добавление лямбда-выражений и Stream API.
Java 11 2018 LTS-релиз Новый HTTP-клиент, возможность запускать файлы без предварительной компиляции.
Java 21 2023 Новейший LTS Внедрение виртуальных потоков (Project Loom) для высочайшей производительности.
